# Retro Track Discos

#### O Retro Track Discos é um projeto front-end de um e-commerce de discos de vinyl. Esta página foi desenvolvida durante a graduação em Sistemas de Informação para a disciplina de Programação em Ambiente Web.
#### O objetivo foi aplicar na prática conceitos sobre css, html, diagramação de página web que aprendemos em sala de aula.

## Pré-requisitos recomendados:

### - VS Code versão 1.120.0 ou superior:
https://code.visualstudio.com/

## Instalação:

### 1- Baixar e instalar o VS Code;
### 2- Clonar este repositório com o Git ou fazer o download dos arquivos diretamente pelo Github;
### 3- Abrir o projeto na pasta armazenada;
### 4- Executar o projeto
